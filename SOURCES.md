# Full sources

Core modules on GitHub: AppLock.kt, AhxVault.kt, manifests, Gradle, Actions.

**MainActivity.kt** and **AresJarvis.kt** (full launcher + assistant UI) are in the release package:
`AresNova-Android-v1.3.zip` from Grok.

Copy them into:
`app/src/main/java/com/nova/launcher/`

Then run Actions → Build APK, or open in Android Studio.
