# Ares Nova v1.3 (Android APK)

iPhone-style home launcher on Android + Ares Jarvis + Ahx encryption + launcher PIN + password vault.

## Android capabilities used
Open apps, dialer, camera, browser, Wi-Fi/Bluetooth/Settings screens, flashlight, sealed notes/passwords, optional cloud Worker.

## Passwords / PIN
- `set pin 1234` — locks this launcher when it opens (not the phone system lock)
- `set root` + `save pass gmail secret` / `get pass gmail` — encrypted password store (Ahx)

## iOS-style UI
Layout patterns only (grid, dock, gestures). No Apple proprietary source code is included or copied.

## Install
1. Actions → Build APK → download artifact
2. Install APK → Settings → Default apps → Home → Ares Nova

Termux: store/open the APK; prefer Actions for compile.
